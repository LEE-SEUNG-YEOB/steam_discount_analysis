# Steam 할인 패턴 분석 프로젝트

Steam 게임의 가격 할인 패턴을 장르별로 분석하여,
할인 효과의 차이를 비교하는 데이터 분석 프로젝트입니다.

## 핵심 질문

- 할인이 모든 게임에 똑같이 효과적인가?
- 장르별로 할인 반응 패턴은 어떻게 다른가?

## 사용 데이터

- Steam Web API (게임 메타데이터, 리뷰)
- IsThereAnyDeal API (할인 이력)

## 분석 도구

- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook
