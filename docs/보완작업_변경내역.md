# 보완 작업 변경 내역 — 일반인도 이해할 수 있는 요약

> 교수님 피드백을 받은 후 프로젝트를 어떻게 고쳤는지 정리한 문서입니다.

---

## 1. 연구 주제 표현 변경

### 뭐가 바뀌었나

**이전:** "Steam 게임 할인 효과를 분석한다"

**이후:** "Steam 게임 할인이 사용자 참여도(Engagement)에 미치는 변화를 분석한다"

### 왜 바꿨나

교수님이 "할인 효과라고 했는데, 매출 데이터도 없이 어떻게 효과를 측정하냐?"라고 지적하셨습니다.

Steam 게임의 실제 매출(얼마나 팔렸는지)은 Steam 개발사인 Valve의 영업 비밀이라 외부에서 절대 알 수 없습니다. 그러니 "매출에 어떤 효과를 미쳤다"고 말하는 건 근거가 없는 주장이 됩니다.

대신 우리가 실제로 측정할 수 있는 건 리뷰 수의 변화입니다. 리뷰를 쓰려면 게임을 실제로 플레이해야 하니까, 리뷰가 늘었다는 건 그만큼 사람들이 게임을 더 많이 하고 있다는 신호입니다. 이걸 "사용자 참여도(Engagement)"라고 부르기로 했습니다.

---

## 2. 지표 이름 변경

| 이전 이름 | 이후 이름 |
|----------|----------|
| 반응률 | **Engagement 반응률** |
| 유지율 | **Engagement 유지율** |

할인 중에 리뷰가 얼마나 늘었는지 = Engagement 반응률

할인이 끝나고 2주 뒤에도 리뷰가 평소보다 얼마나 많은지 = Engagement 유지율

---

## 3. 장르 이름 변경

| 이전 | 이후 |
|------|------|
| Casual/Indie | **Casual/Lightweight** |

"Indie(인디)"는 장르가 아니라 게임을 만든 회사의 규모를 뜻합니다. 대형 회사가 아닌 소규모 팀이 만든 게임이면 인디라고 부르죠. 그래서 장르 이름으로 쓰기엔 맞지 않아서, "가볍게 즐길 수 있는 게임"이라는 뜻의 Lightweight로 바꿨습니다.

---

처음에 게임을 5개 장르로 나눌 때 실수가 있었습니다. 대표적인 오류들:

| 게임 | 이전 분류 | 수정 후 | 이유 |
|------|----------|---------|------|
| PAYDAY 2 | RPG | **Action** | 은행 강도 협동 슈팅 게임인데 RPG로 잘못 분류됨 |
| Stardew Valley | RPG | **Casual/Lightweight** | 농장 경영 게임, RPG가 아님 |
| ELDEN RING | Action | **RPG** | 스토리와 성장 시스템이 핵심인 액션 RPG |
| Black Myth: Wukong | Action | **RPG** | 동일한 이유 |
| Battlefield 2042 | Adventure | **Action** | 군사 FPS 게임이 어드벤처? 명백한 오류 |
| Sekiro | Adventure | **Action** | 순수 액션 게임 |
| Hogwarts Legacy | Adventure | **RPG** | 오픈월드 RPG |

## 5. 분석 대상 게임 변경 (55개로 확장)

### 왜 바꿨나

재분류 과정에서 장르별 게임 수가 불균형해졌습니다. Adventure는 7개, 다른 장르는 11개가 됐습니다. 공정한 비교를 위해 균형을 맞췄습니다.

### 추가된 게임

**Adventure (4개 추가)**
- Stray (고양이 주인공 어드벤처)
- It Takes Two (협동 어드벤처)
- Control (액션 어드벤처)
- Ori and the Will of the Wisps (메트로배니아)

**Strategy/Simulation (1개 추가)**
- RimWorld (식민지 생존 시뮬레이션)

### 교체된 게임 (할인 이력 없거나 오류)

| 제거된 게임 | 이유 | 대체 게임 |
|-----------|------|----------|
| The Witcher 3 | 리뷰 100개만 수집됨 (API 오류) | NieR:Automata → 이후 다시 교체 |
| ARK: Survival Evolved | 2023년에 무료 게임으로 전환됨 | Monster Hunter: World |
| NieR:Automata | 할인 이력 없음 | Divinity: Original Sin 2 |
| Factorio | 개발사 정책상 Steam 할인 안 함 | Vampire Survivors |
| Project Zomboid | 할인 이력 없음 | Cities: Skylines |

### 최종 구성: 5개 장르 × 11개 게임 = 55개

## 6. 리뷰 데이터 수집 방식 개선

### 이전 방식

하루에 리뷰가 몇 개 달렸는지만 기록 (일별 집계)

→ 각 리뷰를 쓴 사람이 얼마나 플레이했는지, 긍정 리뷰인지 부정 리뷰인지 알 수 없었음

### 새로운 방식

리뷰 하나하나를 개별 기록

→ 수집 항목: 플레이 시간 / 추천 여부(긍정·부정) / 리뷰 작성 시점 / 언어 등

→ 총 2,574,740개 개별 리뷰 수집

## 7. 새로운 분석 3가지 추가

### 분석 1 — 플레이타임 필터 민감도 분석

"리뷰 쓴 사람의 플레이 시간 기준을 바꿔도 결론이 같은가?"를 검증했습니다.

- 전체 리뷰 포함
- 2시간 이상 플레이한 사람만 (Steam 환불 가능 시간이 2시간이라, 2시간 이상이면 환불 안 한 진짜 플레이어)
- 5시간 이상 플레이한 사람만

세 기준 모두에서 장르 순위가 동일하게 나왔습니다 → "우리 분석이 기준을 바꿔도 흔들리지 않는다"고 방어 가능

### 분석 2 — 긍정률 변화 분석

할인 전·중·후로 "긍정 리뷰 비율"이 어떻게 변하는지 봤습니다.

"할인으로 들어온 사람들이 게임을 만족했나?" 를 확인하는 분석입니다.

결과: 전반적으로 할인이 평판을 크게 훼손하지는 않았음. Action 장르는 할인 중 소폭 하락(-1.9%p).

### 분석 3 — 장르별 플레이타임 분포

"RPG 유저랑 Casual 유저가 실제로 플레이 시간이 다른가?"를 데이터로 확인했습니다.

| 장르 | 중앙값 플레이타임 |
|------|----------------|
| RPG | 50.9시간 |
| Action | 45.9시간 |
| Strategy/Simulation | 36.1시간 |
| Casual/Lightweight | 28.5시간 |
| Adventure | 18.2시간 |

→ 장르마다 소비 방식이 다르다는 데이터 근거 확보. "왜 장르로 나눴냐"는 교수님 질문에 대한 답변.

---

## 요약 — 한 줄로 정리

처음엔 "할인이 얼마나 팔리게 하는가"를 분석하려 했지만, 매출 데이터를 얻을 수 없어서 **"할인이 사용자들을 얼마나 더 활발하게 만드는가"** 로 연구 방향을 명확히 바꿨고, 그에 맞게 데이터·분석·용어를 전면 정비했습니다.
