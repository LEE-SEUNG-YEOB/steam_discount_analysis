# 평균(Mean) vs 중앙값(Median) — 발표 대비 정리

> 발표 중 "왜 중앙값을 썼나요?" 질문 대비용 정리.
> 본 프로젝트에서 모든 차트·통계 검정이 중앙값 기준으로 통일된 이유.

---

## 1. 기본 개념

### 평균 (Mean)

모든 값을 더하고 개수로 나눈 값.

```
평균 = (모든 값의 합) ÷ 데이터 개수
```

**특징**: 모든 데이터 포인트가 결과에 영향을 줌. 그래서 극단값(매우 크거나 작은 값)에 민감.

### 중앙값 (Median)

값을 크기 순으로 정렬했을 때 **정중앙에 위치하는 값**.

```
[1, 3, 5, 7, 9]
       ↑
    중앙값 = 5
```

**특징**: 데이터의 50% 지점을 표시. 극단값이 있어도 흔들리지 않음.

---

## 2. 둘이 차이 나는 경우

### 정상 분포 (대칭) — 거의 같음

5명의 키(cm):

```
[160, 165, 170, 175, 180]
```

- 평균: 170
- 중앙값: 170

→ 좌우 대칭이면 평균 = 중앙값.

### 비대칭 분포 (한쪽 꼬리가 김) — 크게 달라짐

5명의 키에 거인 1명 추가:

```
[160, 165, 170, 175, 250]
                       ↑
                    이상값
```

- 평균: 184 (거인 한 명 때문에 14cm나 뛰어버림)
- 중앙값: 170 (그대로 유지)

→ **어느 쪽이 "보통 사람 키"를 더 잘 나타내는가? → 중앙값**

## 3. 본 프로젝트에서 왜 중앙값을 선택했나

### 이유 ① — 반응률 데이터가 비대칭

`reaction_rate` (반응률) 데이터의 분포를 보면:

- 대부분 이벤트: **0.05 ~ 0.5** 사이에 모여 있음
- 일부 극단 이벤트: **3.0, 5.0, 심지어 8.0 이상** 존재

이런 극단값이 왜 생기는가? 반응률 공식 때문입니다:

```
반응률 = (할인 중 일평균 리뷰 - 직전 30일 일평균) / 직전 30일 일평균
```

만약 직전 30일에 **하루 1개**만 리뷰가 있던 게임이 할인 중 **하루 10개**가 되면:

```
(10 - 1) / 1 = 9.0  → 반응률 9배 (900%)
```

이런 게임이 1~2개만 끼어도 **평균이 폭증**합니다.

### 실제 데이터 사례 — 할인율 0~30% 구간

이 구간 59건의 반응률:

| 통계량 | 값        |
| ------ | --------- |
| 평균   | **0.471** |
| 중앙값 | **0.108** |
| 최댓값 | 약 7.0+   |

→ **평균은 0.471인데, 그 안에 들어 있는 보통 이벤트는 0.108 수준**. 극단 이벤트가 평균을 4배 이상 부풀린 것.

→ "이 구간 게임의 보통 반응률은?" 이라는 질문에는 **중앙값 0.108**이 정답.

### 이유 ② — 통계 검정과의 일관성

본 프로젝트가 사용한 통계 기법들:

- **Kruskal-Wallis 검정** (장르 간 차이) → **비모수 검정** → 중앙값 기반
- **Spearman 상관** (할인율-반응률) → **순위 기반** → 중앙값과 동일 철학
- **Mann-Whitney U 검정** (시즌 vs 비시즌) → **비모수 검정** → 중앙값 기반
- **부트스트랩 95% CI** (장르별 신뢰구간) → **중앙값 부트스트랩** 사용

→ 모든 분석이 **중앙값 기준**으로 통일되어 있는데, 차트만 평균을 쓰면 인사이트와 시각화가 따로 놀게 됨.

### 이유 ③ — 발표 메시지와의 일치

본 프로젝트의 핵심 발견:

- 할인율 효과: **단조 증가 (낮음 → 높음으로 일관되게 증가)**
- 장르 차이: **약함 (모든 장르 비슷한 수준)**

이건 모두 **중앙값 기준**의 결과입니다. 만약 평균을 쓰면:

- 할인율 0~30% 구간이 극단값 때문에 가장 높게 보임 → **단조 증가 안 보임**
- 장르별 평균 차이가 극단값 때문에 크게 보임 → **"장르 차이 약함" 메시지와 모순**

→ 시각화도 분석 결과와 같은 메시지를 전달하려면 **중앙값**이어야 함.

## 4. 발표 Q&A 대비

### Q1. "왜 평균을 안 쓰고 중앙값을 썼나요?"

**답변**:

> 반응률 데이터가 우측 꼬리가 긴 비대칭 분포라, 일부 극단 이벤트가 평균을 왜곡할 수 있기 때문입니다. 예를 들어 직전 리뷰가 거의 없던 게임에서 할인 후 약간만 늘어나도 반응률이 수백 % 단위로 측정될 수 있고, 이런 한두 건이 전체 평균을 끌어올립니다.
>
> 본 프로젝트의 모든 통계 검정도 비모수 기준(Kruskal-Wallis, Spearman, Mann-Whitney)이라 중앙값 철학과 일치합니다. 따라서 시각화도 중앙값으로 통일해 분석 결과와 일관성을 유지했습니다.

### Q2. "그럼 평균은 안 좋은 건가요?"

**답변**:

> 평균이 항상 나쁜 것은 아닙니다. 정규분포처럼 대칭적인 데이터에서는 평균과 중앙값이 거의 같고, 평균이 모든 데이터를 반영한다는 장점이 있습니다.
>
> 다만 본 프로젝트의 반응률 데이터는 비대칭이고 극단값이 존재하므로, 보통의 이벤트 패턴을 더 잘 대표하는 중앙값이 적절하다고 판단했습니다.

### Q3. "중앙값을 쓰면 정보를 잃는 거 아닌가요?"

**답변**:

> 단일 지표로는 그렇게 볼 수 있지만, 본 프로젝트는 중앙값 외에도 부트스트랩 95% 신뢰구간으로 분산까지 함께 제시합니다. 따라서 중앙값과 신뢰구간의 너비를 함께 보면 분포의 안정성도 확인할 수 있습니다.
>
> 또한 평판 변화 분포처럼 분포 자체가 중요한 경우는 별도 차트로 분리해 표시했습니다.

### Q4. "그러면 평균은 어디에 썼나요?"

**답변**:

> 본 프로젝트에서는 비율 지표(긍정률 자체, 평판 변화 그룹 비율 등) 외에는 평균을 사용하지 않았습니다. 비율 지표는 0~1 사이 값으로 극단값 위험이 작아 평균도 안전하기 때문입니다.

### Q5. "다른 연구에서는 평균을 쓰는 경우도 많지 않나요?"

**답변**:

> 맞습니다. 다만 그건 데이터 특성에 따라 다릅니다. 정규분포 가정이 성립하거나 표본 크기가 매우 큰 경우 평균이 안정적입니다. 본 프로젝트는 표본 261건에 우측 꼬리가 긴 분포라, 견고함이 더 중요하다고 판단해 중앙값을 선택했습니다.

## 6. 한 줄 요약

> **평균은 모든 값을 반영하지만 극단값에 휘둘리고,
> 중앙값은 정중앙 값으로 비대칭 데이터에서도 안정적이다.**
>
> 본 프로젝트의 반응률 데이터는 우측 꼬리가 긴 비대칭이고,
> 모든 통계 검정이 비모수 기준이므로 **중앙값**을 일관되게 사용한다.

## 7. 슬라이드 1장 요약 (PPT 삽입용)

발표 자료에 한 슬라이드로 넣고 싶다면 이렇게 구성:

```text
[제목] 왜 중앙값을 사용했는가

[좌측: 비유 그림]
교실 평균 재산
  → 빌게이츠 한 명 들어오니 평균이 1억 달러
  → 그래도 보통 학생 재산은 200만원

[우측: 본 프로젝트 데이터]
할인율 0~30% 구간 반응률 (n=59)
  - 평균: 0.471 (극단 이벤트가 끌어올림)
  - 중앙값: 0.108 (보통 이벤트의 진짜 모습)
  - 최댓값: 7.0+ (극단값)

[하단 결론]
반응률 데이터가 우측 꼬리가 긴 비대칭 분포라,
극단값에 안정적인 중앙값을 채택.
모든 비모수 통계 검정(K-W, Spearman, M-W)과도 일관됨.
```

## 8. 추가 학습 (선택)

조금 더 깊이 알고 싶다면:

- **Robust statistics**: 극단값에 강한 통계 (중앙값이 대표적)
- **MAD (Median Absolute Deviation)**: 중앙값의 표준편차 버전
- **Trimmed mean**: 평균과 중앙값의 중간 — 양극단 일부 제외하고 평균
- **분포의 왜도(skewness)**: 비대칭 정도를 수치로 측정

본 발표에는 이런 깊은 통계까지 안 들어가도 되지만, 교수님이 깊이 물으시면 "사용한 데이터의 왜도가 크게 양수라 우측 꼬리가 길고, 따라서 중앙값이 적절합니다" 같은 한 마디 추가하면 좋습니다.
